# Security Policy

## Supported versions

| Version | Supported          |
|---------|--------------------|
| 4.x     | Yes                |
| 3.x     | Critical fixes only |
| < 3.0   | No                 |

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through
[GitHub security advisories](https://github.com/goaop/framework/security/advisories/new) instead.

Include the affected version, a description of the problem and, if possible, a minimal reproduction. You will get an
answer within a few days; once a fix is ready, it is released together with a published advisory.
